# Contributing

Issues and pull requests are welcome. Please open pull requests against the `keykeeper` branch.

The project's rules are in [AGENTS.md](AGENTS.md) and, for all three repositories, in the [PassBundle repository](https://github.com/PimpinPumpkin/Passbundle/blob/main/AGENTS.md). In short:

- Write tests with your change. The end-to-end tests live in the PassBundle repository.
- Build only the open-source configurations.
- Don't change encryption, key handling, or sign-in behavior without a design note and a test.
- Write in US English.
